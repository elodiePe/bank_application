# Photos de la landing page

Dépose ici les vraies photos, avec exactement ces noms de fichier — la page les charge
automatiquement dès qu'elles existent (repli sur l'illustration dessinée tant qu'un fichier
est absent, donc rien ne casse en attendant) :

- `hero-family.jpg` — une famille heureuse, image principale en haut de page (format portrait, ratio 4:5, ~1200×1500 ou plus).
- `child-coins.jpg` — un enfant heureux qui compte ses pièces (format portrait ou carré, ~900×900).
- `savings.jpg` — l'épargne / un enfant qui met une pièce dans une tirelire (format portrait ou carré, ~900×900).

Formats acceptés : `.jpg`, `.jpeg` ou `.png` (même nom de base, l'extension est essayée dans cet
ordre). Compresse les photos avant de les déposer (viser < 300 Ko chacune) pour ne pas alourdir
le chargement de la page.
